# Balikin

Static Lost & Found campus prototype.

## Deploy to Vercel

Import this repository in Vercel and select **Other** as the framework preset. Leave the build command and output directory empty; Vercel serves the root `index.html` directly.

## Run locally

Open `index.html` in a browser, or use a static server:

```sh
npx live-server --host=0.0.0.0 --port=8080
```

Use `http://<your-local-IP>:8080` from a phone on the same Wi-Fi network.

> This is a prototype. Login, locker, photo processing, and matching are simulated in the browser only.
